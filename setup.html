INSTALLATION // WINDOWS & MULTI-SERVER

NEXUS RICHTIG EINRICHTEN.

Von der ZIP-Datei bis zum fertigen Discord-Server. Die Checkliste speichert deinen Fortschritt nur lokal im Browser.

VoraussetzungenDiscord PortalLokale InstallationErster StartServer einrichtenMulti-ServerFunktionstest
Wichtig: Poste deinen Bot-Token niemals auf Discord, einer Website oder im Chat. Er gehört nur in deine lokale .env.

1. Voraussetzungen

CMD
node -v

2. Discord Developer Portal

  1. Erstelle oder öffne deine Nexus-Anwendung.
  2. Kopiere die Application ID.
  3. Erstelle unter „Bot“ einen Token.
  4. Aktiviere Server Members Intent und Message Content Intent.
  5. Lade den Bot mit den Scopes bot und applications.commands ein.
  6. Setze die Botrolle auf dem Testserver weit nach oben.

3. Lokale Installation

Starte im entpackten Bot-Ordner:

0-START-HIER.bat1-INSTALLIEREN.bat2-BOT-STARTEN.bat3-COMMANDS-REGISTRIEREN.bat5-SYSTEM-PRUEFEN.bat

Nutze zuerst den Installationspunkt. Der Assistent erstellt deine private .env.

4. System prüfen und starten

015-SYSTEM-PRUEFEN.batPrüft Node, Dateien und Installation.
023-COMMANDS-REGISTRIEREN.batRegistriert Slash-Commands.
032-BOT-STARTEN.batStartet Nexus.

Teste danach:

/ping/status/botinfo/help

5. Discord-Server einrichten

1/setup assistant

Zeigt dir die komplette Reihenfolge.

2/setup diagnose

Findet fehlende Rechte und Zuordnungen.

3/config brand

Name, Footer und Farbe festlegen.

4/config minecraft

IP, Port und Edition speichern.

5/config module

Welcome, Level, Economy und Schutzmodule aktivieren.

6/setup quickstart

Erstellt die komplette Serverstruktur.

7/config overview

Alles kontrollieren.

8/setup diagnose

Abschlussprüfung durchführen.

6. Andere Server zulassen

Für den ersten Test kannst du eine GUILD_ID setzen. Wenn Nexus auf mehreren Servern genutzt werden soll:

.ENV
GUILD_ID=

Registriere anschließend die Commands erneut. Jeder Serveradministrator richtet ausschließlich seinen eigenen Server über /setup und /config ein.
