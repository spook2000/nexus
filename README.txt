NEXUS WEBSITE 2.0.1
====================

Start:
1. Ordner in VS Code öffnen.
2. Live Server installieren.
3. index.html mit Live Server öffnen.

Vor dem Onlinegang:
- In site-config.js den echten Discord-Bot-Einladungslink eintragen.
- Optional einen Support-Server-Link eintragen.
- impressum.html mit echten Pflichtangaben ausfüllen.
- Texte und Links prüfen.

Inhalt basiert auf Nexus Multi-Server 2.0.1:
- 83 Slash-Commands
- 136 Aktionen
- Multi-Server-Konfiguration
- Quickstart, Tickets, Bewerbungen, Security und Minecraft-Status
- Keine Livechat-Bridge / kein /mcchat

Die Website enthält kein Backend und keine Tracking-Skripte.
